# Pizza-Sales-SQL-PowerBI-Analysis
This project analyzes a pizza restaurant's sales data using SQL for data extraction and KPI calculations and Power BI for interactive dashboard visualization.  The objective is to uncover business insights, identify customer purchasing patterns, and provide actionable recommendations using data analytics.

# 🍕 Pizza Sales Analysis | SQL + Power BI

## 📌 Project Overview

This project analyzes pizza sales data using SQL and Power BI to uncover business insights and support data-driven decision-making.

The project focuses on revenue analysis, customer ordering behavior, product performance, and sales trends through KPI calculations and interactive dashboards.

---

## 🎯 Business Problem

The business wants to answer the following questions:

- What is the total revenue generated?
- What is the average order value?
- How many pizzas were sold?
- Which pizzas generate the highest revenue?
- Which pizzas perform poorly?
- Which pizza category contributes the most revenue?
- Which pizza size is most popular?
- What are the daily and monthly sales trends?

---

## 📂 Dataset

The dataset contains pizza sales transaction data with the following fields:

- Unit Price
- Total Price
- Order Date
- Order Time

---

# 📈 Key Performance Indicators

### Total Revenue
Measures the total revenue generated from all pizza sales.

### Average Order Value
Calculates the average amount spent by customers per order.

### Total Orders
Shows the total number of customer orders.

### Total Pizzas Sold
Displays the total quantity of pizzas sold.

### Average Pizzas per Order
Calculates the average number of pizzas purchased in each order.

# 📌 Key Business Insights

- Large pizzas generated the highest revenue.
- Classic pizzas contributed the highest percentage of total sales.
- Weekends recorded the highest order volume.
- Peak ordering hours occurred during lunch and dinner.
- Top five pizzas generated the majority of total revenue.
- Bottom-selling pizzas need promotional strategies.

---

# 💡 Business Recommendations

- Promote low-selling pizzas using combo offers.
- Increase inventory for high-demand pizzas.
- Schedule more staff during peak hours.
- Focus marketing campaigns on best-performing categories.
- Introduce loyalty offers to increase average order value.
